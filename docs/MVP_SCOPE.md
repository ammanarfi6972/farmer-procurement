# MVP Scope

## Must-have

### Farmer

- OTP login (mock/provider abstraction)
- profile
- multilingual switch
- centre map
- centre availability
- slot booking
- booking/token
- queue position
- ETA
- procurement status
- payment status
- notification history

### Staff

- login
- today's schedule
- check-in
- live queue
- call/advance
- procurement entry
- completion

### Manager

- live operations dashboard
- capacity
- wait/service metrics
- centre-level analytics

### District/Admin

- cross-centre dashboard
- centre comparison
- overload/underutilization visibility

### Super Admin

- centres
- commodities
- pricing
- basic schedule/capacity config
- user assignments

### Platform

- PWA
- responsive UI
- realtime queue updates
- mock SMS
- Google Maps
- seeded demo data
- RLS/auth
- audit logs

## Nice-to-have

- waitlist
- advanced slot recommendation
- exportable reports
- richer notification templates
- centre heatmap
- historical trend views

## Out of scope

- AI/ML
- real Aadhaar
- real bank APIs
- hardware
- real SMS billing
- real government API certification/integration
- offline mutation conflict resolution
- native mobile apps

## Prioritization rule

A new feature is accepted only when it strengthens:

1. farmer waiting-time reduction;
2. schedule clarity;
3. queue visibility;
4. operational control;
5. procurement/payment transparency;
6. SIH demo impact.

Everything else is secondary.
